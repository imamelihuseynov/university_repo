1. Git

Definition: Git is a tool that tracks changes in files and helps people work together on projects.
Example: I used Git to save changes to my README file.

2. GitHub

Definition: GitHub is a website where Git repositories are stored and shared online.
Example: Our team keeps the project on GitHub.

3. Repository (Repo)

Definition: A repository is a folder that contains a project's files and history.
Example: The README.md file is stored in our repository.

4. Commit

Definition: A commit is a saved snapshot of changes in a project.
Example: I made a commit after updating the documentation.

5. Branch

Definition: A branch is a separate workspace for making changes without affecting the main project.
Example: I created a branch called docs/readme.

6. Main Branch

Definition: The main branch is the primary version of a project.
Example: All approved changes are merged into the main branch.

7. Clone

Definition: Cloning means downloading a copy of a repository to your computer.
Example: I cloned the repository before starting my task.

8. Push

Definition: Push sends your local commits to GitHub.
Example: After committing my work, I pushed it to GitHub.

9. Pull

Definition: Pull downloads the latest changes from a remote repository.
Example: I pulled the newest version before editing the files.

10. Pull Request 
Definition: A pull request asks for changes from one branch to be reviewed and merged into another branch.
Example: I opened a pull request for my README updates.
